## Project Overview

This repository contains 28 practical assignments developed using HTML5, CSS3, and PHP.

The assignments demonstrate web development concepts such as HTML forms, CSS styling, PHP programming, form handling, input validation, decision-making statements, functions, string manipulation, calculations, and responsive web design.

---

## Objectives

- To understand HTML5 form creation.
- To design web pages using CSS3.
- To process form data using PHP.
- To perform calculations using PHP.
- To implement decision-making statements.
- To create and use user-defined functions.
- To validate user input.
- To display appropriate success and error messages.
- To develop simple web applications using HTML, CSS, and PHP.
